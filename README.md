# Expat Roasters Company Vault

Private AI context vault for Expat Roasters business work. Used to keep project continuity across AI tools.

## Rules
- Keep this repository PRIVATE. Confirm with company policy before adding any data.
- Store summaries, not raw chat exports. Summaries are the fast context layer.
- Never commit passwords, API keys, tokens, bank or account numbers, ID numbers, or personal health data.
- Do not commit employee performance or disciplinary records.
- Do not assume a project's status from its summary. Check the current source.
- Git history keeps deleted content. If a secret is committed, rotate it and rewrite history.
- Never enable GitHub Pages on this repository.

## Layout
- `memory/START_HERE.md`: index every AI assistant reads first.
- `projects/`: one current-state summary per active project.
- `decisions/`: dated decisions, one entry each (see template in `decisions/README.md`).
